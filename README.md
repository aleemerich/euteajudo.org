# EuTeAjudo.org

Anonymous space where people describe what they are going through and receive supportive replies. This repository holds the WordPress platform: a custom plugin and a block theme.

- Domain language and documentation are in Portuguese: start with [GLOSSARY.md](GLOSSARY.md) and [docs/mvp.md](docs/mvp.md).
- Contributors and coding agents: read [AGENTS.md](AGENTS.md).
