# Kit para redes sociais e vídeo

Modelos em SVG da identidade "Luz acesa". Regras completas em [../identity.md](../identity.md).

| Arquivo | Tamanho | Uso |
|---|---|---|
| `post-night.svg` | 1080 × 1080 | Post quadrado (padrão) |
| `post-day.svg` | 1080 × 1080 | Post quadrado para conteúdo informativo longo |
| `story-night.svg` | 1080 × 1920 | Stories e Reels (capa) |
| `video-cover.svg` | 1280 × 720 | Capa de vídeo |
| `subtitle-band.svg` | 1920 × 1080 | Sobreposição transparente: faixa de legenda e símbolo no canto |
| `../logo/social-avatar.svg` | 512 × 512 | Foto de perfil |

Como usar:
- Os textos são texto editável. Para editar no Figma, Canva ou Inkscape, instale antes a fonte de `../fonts/` (Atkinson Hyperlegible Next); sem ela, o editor troca a fonte.
- Uma ideia por peça, frases curtas, no tom de voz do site. Sem exclamações nem emojis.
- Nunca usar textos reais de Pedidos ou depoimentos, mesmo anônimos.
